# London-Housing-Affordability-Analysis-using-R
# London Housing Affordability Analysis

This project analyses housing affordability across London boroughs using R.

## Research Question
Which London boroughs are least affordable, and how does affordability vary with local earnings and rental costs?

## Data Sources
- ONS house price to workplace-based earnings ratio
- London Datastore borough-level housing and rent data

## Methods
- Data cleaning
- Descriptive statistics
- Borough ranking
- Data visualisation with ggplot2
- Linear regression analysis

R, RStudio, ggplot2, dplyr
